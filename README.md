# GUI_for_Seismic_Fragility

Welcome to the repository of **GUI_for_Seismic_Fragility**, a MATLAB-based graphical user interface (GUI) developed for component- and system-level parameterized seismic fragility and resilience assessment of structures.

The application provides a user-friendly platform for conducting seismic vulnerability assessments, generating fragility and resilience curves, and evaluating structural performance under different conditions.

## Key Features

- Component-level parameterized seismic fragility assessment.
- System-level seismic fragility assessment.
- Generation and visualization of seismic fragility curves.
- Seismic resilience assessment and visualization.
- User-friendly graphical interface for performing analyses.

## Software Requirements

**MATLAB is required to run this application.**

- The application is developed using MATLAB.
- A compatible MATLAB installation is necessary.
- This application is not a standalone executable and cannot be directly run without MATLAB.

## How to Download the Application

Follow these steps to download the application:

1. Navigate to this GitHub repository.
2. Click on the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to your preferred location.
5. Alternatively, clone the repository using Git:

   `git clone <repository-url>`

## How to Run the Application

1. Open MATLAB on your computer.
2. Navigate to the folder where you extracted the downloaded application.
3. Set the application folder as the **Current Folder** in MATLAB.
4. Locate and open the main MATLAB application file (`.mlapp` or the designated main program file).
5. Run the application using MATLAB to access its graphical user interface.

**Note:** The application must be executed within MATLAB. Downloading the repository alone will not run the application.
